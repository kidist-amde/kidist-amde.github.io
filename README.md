---

## 🛠️ Built With

[Academic Pages](https://academicpages.github.io/) Jekyll template, hosted on GitHub Pages.

### Run locally

```bash
bundle install
jekyll serve -l -H localhost
```

Then open `http://localhost:4000`.

| Path | Purpose |

| `_pages/cv.md` | CV page |

| `_portfolio/` | Research highlight pages |
